# DeepSeek 自动朗读

一个 Tampermonkey 油猴脚本，让 DeepSeek Chat（chat.deepseek.com）自动朗读 AI 回复。

## 功能

| 功能 | 说明 |
|------|------|
| **自动朗读** | AI 回复完成后自动朗读，流式输出时不触发 |
| **暂停/继续** | 听到一半可以暂停，回来继续听，不用从头开始 |
| **朗读进度** | 右下角实时显示已读百分比 |
| **重读** | 点一下按钮重新朗读最后一条回复 |
| **面板拖拽** | 按住面板空白处拖到不碍事的位置 |
| **位置记忆** | 拖拽位置刷新页面后自动还原 |
| **开关控制** | 随时关闭/开启自动朗读 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开本文件（.user.js），Tampermonkey 会自动识别并提示安装
3. 打开 [DeepSeek Chat](https://chat.deepseek.com/)
4. 在页面上**点一下鼠标**（激活语音权限）
5. AI 回复后自动朗读

## 使用说明

- **首次使用**：页面加载后随便点一下页面任意位置，浏览器才会允许朗读
- **暂停/继续**：朗读时右下角出现暂停按钮，点它暂停，再点继续
- **重读**：点 🔁 按钮重新读最后一条回复
- **移动面板**：按住面板空白区域拖到任何位置，下次打开页面自动还原
- **关闭朗读**：点「关」按钮，面板变红表示已关闭
